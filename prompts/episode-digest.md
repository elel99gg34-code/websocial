## 지켜야 할 것
1. summary 는 200자 내외. 다음 화를 쓸 작가가 읽고 바로 이어 쓸 수 있어야 한다.
2. newFacts 에는 "이 회차로 확정되어 앞으로 바꿀 수 없는 사실"만 넣는다.
   분위기나 감상은 넣지 않는다. 인물의 부상·이동·관계 변화·밝혀진 정보가 대상이다.
3. characterUpdates 는 이번 화에 상태가 바뀐 인물만 넣는다.
4. foreshadowPlanted 는 이번 화에서 새로 심은 복선만. id 는 `fs-` 로 시작하는 짧은 키.
5. foreshadowResolved 에는 이번 화에서 회수된 복선의 id 만 넣는다. 없으면 빈 배열.
6. endingHook 은 이번 화가 실제로 어떻게 끝났는지 한 문장으로.
